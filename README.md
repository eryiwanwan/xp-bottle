# 小妈的性癖之瓶

18+ 成人向自测小游戏。刷完 35 张（或 30 张）卡，得到一张属于自己的瓶子海报。

**内容边界**：词表只到"分类标签"这一层，不写行为描述、不写操作指导。全程 18+ 门禁，不涉及未成年，强制类只作幻想标签存在。

## 本地运行

纯静态，不需要构建、不需要依赖安装。**必须用 HTTP 服务打开**，直接双击 `index.html` 会因为 `file://` 协议限制导致部分功能异常。

```bash
cd xp-bottle
python -m http.server 8080
# 打开 http://localhost:8080
```

也可以用 `npx serve .` 或任何静态服务器。

## 文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | 全部界面 + 业务逻辑（刷卡、海报、存图、对撞、邀请） |
| `bottle.js` | 瓶身引擎：13 种瓶型 × 5 档液面，纯 SVG |
| `types.js` | 倾向类型：9 型（位置 × 强度）+ 边界前缀 + 文案 |
| `match.js` | 两瓶对撞：逐项一致性归一 + 四个分区 |
| `og.png` | 分享预览图 1200×630（发链接给 X / Discord 时的缩略图） |
| `preview.html` | 断点预览：一次看 375 / 768 / 1024 / 1440 四档（开发用） |
| `bottles.html` | 瓶型视觉预览页（开发用，不是游戏的一部分） |
| `词表.md` | 95 个词条的可读清单 + 风险项清单（内容审核用，脚本生成） |
| `tools/make-og.py` | 重新生成 `og.png` 的脚本（改了封面文案就跑一次） |
| `spec.md` | 交互规格：状态机、手势阈值、算法公式、文案表、验收清单 |

改完东西要重新生成的两份文件：

```bash
python tools/make-og.py     # 预览图，需要 Pillow
node tools/make-words.js    # 词表文档
```

## 技术要点

- **无后端**。答案以六进制压成 base36 存在 URL `#` 后面（35 项约 17 字符），昵称作为末段。服务端永远看不到答案。
- **无账号**。localStorage 只存一个键 `xp18`，标记已确认成年。
- **无框架**。总 JS 约 30KB，唯一的第三方依赖是二维码库。
- **外部依赖**：`qrcode-generator@1.4.4`（jsDelivr）。挂掉时二维码位置降级成灰框，海报其余部分正常。

## 链接格式

```
#fem.f.1.yk6yk6yk6yk6yk6.%E5%B0%8F%E7%8C%AB
 ↑   ↑ ↑ └─ 答案编码（六进制 → base36）
 │   │ └─ 位置：0 主导 / 1 服从 / 2 交换 / 3 只是想想
 │   └─ 性别：f 女 / m 男 / x 其他 / n 不说
 └─ 词表：basic / deep / fem
```

性别位是单个字母、位置位是单个数字，靠这个区分新旧格式。老的三段式、四段式链接仍可打开。

## 三个词表

| key | 名字 | 项数 | 定位 |
|---|---|---|---|
| `basic` | 基础篇 | 35 | 第一次做选这套 |
| `deep` | BDSM 篇 | 30 | 明确一点的 |
| `fem` | 女性向篇 | 30 | 重氛围、言语、照料 |

key 一旦上线就不要改——URL 里存着它。

改词表就改 `index.html` 里的 `DECKS` 常量，格式是 `["词条", "分类", "瓶型", "备注(可选)"]`。分类只有十个：`亲密 / 感官 / 束缚 / 权力 / 言语 / 调教 / 支配 / 道具 / 场景 / 边缘`。

跨词表对撞时靠 `CANON` 表把同义项对齐（`情趣玩具` ≡ `玩具`）。往表里加之前想清楚是不是真的等价——**错配比不配更糟**，它会给出一个看起来合理但是错的分数。
